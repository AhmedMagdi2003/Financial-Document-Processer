AUTOMATION · ZAPIER

Requires Paid Zapier Plan

Zapier Webhook Ingestion

If your organization already has a Zapier Starter/Professional subscription:

  • Trigger: Google Drive > New File in Folder.
  • Action: Webhooks by Zapier > POST (Payload Type: form).
  • Map binary file object to file, add project_id and auto_record=true.
  • Headers: Authorization: Bearer YOUR_REVIEWER_TOKEN.

Note: Webhooks by Zapier is not available on Zapier's free tier. Use Google Apps Script or Make.com for zero cost.
